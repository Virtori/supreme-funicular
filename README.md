# Универсальный отчёт ТОиР

Автономный HTML-отчёт с двумя источниками: универсальная выгрузка заказ-нарядов и выгрузка заявок/позиций ТМЦ из Аспект ЕАМ.

Скачайте `index.html` и откройте в актуальном Chrome или Edge. Сервер, установка и интернет не требуются. Загрузите XLSX, CSV или TSV в оба поля и выберите листы. Можно выбрать один Excel-файл с обоими листами дважды.

Возможности: обзор бэклога, реестры ЗН и ТМЦ, карточки ЗН, фильтры, сводка по планировщикам, просрочка поставок, CSV, печать/PDF и история сохранённых срезов. Кнопка «Сохранить HTML с данными» создаёт переносимый отчёт с текущими данными и историей. Он содержит всю загруженную информацию.

Бэклог по умолчанию: до планирования, планирование, ожидание ресурсов. Расширенный состав добавляет графикование и выполнение. Расчёт ведётся по уникальному номеру ЗН, часы ЗН не суммируются повторно по строкам. Возраст считается от создания. Связь с ТМЦ по номеру ЗН; описание используется только для извлечения единственного известного номера. Завершённые и отменённые позиции не считаются просроченными; частичное получение сохраняет остаток.

Полные правила доступны в раскрывающемся разделе в отчёте. Неизвестные и конфликтующие статусы показаны отдельно и исключены из бэклога. История содержит фактически сохранённые срезы, без реконструкции прошлых состояний. Ресурс на неделю вводится пользователем.

Данные обрабатываются локально. В репозитории нет рабочих выгрузок и сведений предприятия.
