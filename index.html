Как загрузить и как считаются показатели

Загрузите два отдельных XLSX или один файл с двумя листами — выберите его в обоих полях. Лист определяется автоматически; его можно изменить. Поддерживаются также CSV/TSV (UTF-8 или Windows-1251). Старый формат XLS необходимо пересохранить в XLSX.

ЗН считаются по уникальному номеру. Единицы часов задаются во вкладке «Методика SMRP». Итоговые часы ЗН не суммируются по повторным строкам. Трудоёмкость рассчитывается после подтверждения единиц; разные значения блокируют расчёт. Разные значения часов или статусов одного ЗН блокируют соответствующий расчёт.

Возраст — календарные дни с даты создания, а не время нахождения в статусе. Даты после даты среза исключаются из расчёта возраста; состояние статусов отражает саму выгрузку. Изменение даты среза не восстанавливает исторические статусы. Неизвестные статусы не включаются в бэклог, их число показано во вкладке качества.

Просрочка ТМЦ = срок поставки раньше даты среза для незакрытых позиций с неполученным количеством. Позиции без количеств оцениваются по статусу. Частичное получение не закрывает остаток. Количества разных материалов не суммируются. Заявки и позиции показаны отдельно; повторные строки позиций сохраняются, поскольку без идентификатора строки нельзя надёжно отличить дубль от отдельной позиции.

Связь ТМЦ → ЗН только по точному номеру в поле «Заказ-наряд» или одному уникальному номеру из описания, совпавшему с известным ЗН. Совпадение по тексту названия не используется. Нет связи — не означает, что ТМЦ не требуется. Сумма — исходная сумма строк без НДС, без пересчёта на остаток. Тренд строится только по сохранённым срезам, без реконструкции прошлых статусов.

Загрузка заменяет текущую выгрузку выбранного типа. История сохраняется отдельно. После загрузки обоих файлов укажите дату и зафиксируйте срез. Затем сохраните HTML с данными.
